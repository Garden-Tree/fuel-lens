## 3. 詳細な説明（4000 文字以内）

```
FuelLens は、ガソリンスタンドのレシートと、車やバイクのトリップメーターを1枚の写真に撮るだけで、燃費を記録できる無料の燃費管理アプリです。アプリ内課金はありません（解析待ちの画面などに、提携先の紹介（PR）が表示されることがあります）。

■ 写真1枚で記録（AI 読み取り）
レシートとトリップメーターが一緒に写った写真を撮ると、AI（Google Gemini）が給油量・金額・スタンド名と、トリップメーターの区間距離を読み取ります。保存前の確認画面で内容を確認・修正でき、自信のない項目は「要確認」として目立たせます。AI の読み取りには誤りが含まれることがあるので、保存前にご確認ください。

■ 満タン法で燃費と単価を自動計算
前回の満タン給油からの走行距離と給油量から、燃費（km/L）を計算します。支払総額と給油量から単価（円/L）も自動で出します。
・満タンにしなかった給油は「部分給油」として記録し、次の満タン給油でまとめて計算
・トリップメーターの区間距離を入れる方式と、オドメーターの差分から出す方式を、車両ごとに選べます
・記録し忘れた給油があっても、そこで計算を区切れます

■ 履歴と統計
・月ごとの給油履歴（日付・スタンド名・燃料種別・給油量・金額・燃費）
・期間別の平均燃費・最高・最低、費用の合計、1km あたりの費用、平均単価
・燃費・給油代・単価の推移グラフ
・燃料種別（レギュラー / ハイオク / 軽油など）と短いメモを給油ごとに記録

■ 車もバイクも、複数台も
ガソリン車、ディーゼル車、ハイブリッド車、バイクなど、トリップメーターの値と給油量から満タン法で燃費を出せる車両に対応しています。複数の車両を登録し、車両ごとに記録を分けて管理できます。

■ ログインなしでも使えます
手入力・履歴・統計はログインなしで使えます（記録は端末の中に保存されます）。写真からの AI 読み取りと、記録のクラウド保存（複数の端末で共有）にはログインが必要です。ログイン前の記録は、ログイン時に自動で引き継ぎます。

■ バックアップとシェア
・全記録を JSON でバックアップ、CSV で書き出し
・バックアップからの復元は追記のみで、既存のデータは消しません
・今月の燃費をまとめたカード画像を作って共有できます（画像は端末の中で作ります）

■ プライバシー
・レシート・メーターの写真は、AI 読み取りのためにだけ Google の Gemini API に送信します。FuelLens のサーバーやデータベースには保存しません
・ログインにはメールアドレスまたは Google アカウントを使います（パスワードは保持しません）
・提携先の紹介（PR）を表示することがありますが、利用者の記録を提携先へ送ることはなく、情報の販売もしません
・設定画面から、アカウントとクラウドに保存したデータをいつでも削除できます

詳しくはプライバシーポリシー（https://fuel-lens.gadelog.com/privacy）をご覧ください。

■ こんな方に
・給油のたびに燃費をメモするのが面倒な方
・マイカーとバイクなど、複数の乗り物の燃費を比べたい方
・ガソリン代の月ごとの推移を把握したい方

ご意見・ご要望は GitHub Issues（https://github.com/Garden-Tree/fuel-lens/issues）で受け付けています。
```

## 6. アプリのコンテンツ

### 6-1. アプリのアクセス権

「すべての機能がアクセス制限なしで利用可能」ではなく、**一部の機能が制限されている**を選びます。

- 制限される機能: 写真からの AI 読み取りと、クラウド保存（ログインが必要）。手入力・履歴・統計・燃費計算はログインなしで使えます。
- 審査担当者向けの案内: 「ホーム右上の『ログイン』から Google アカウントまたはメールコードでログインできます」。審査用のテストアカウントを用意する場合は `<テスト用アカウントの情報>` を入力欄に書く（本物のパスワードを使い回さない。メールコードでログインするため、受信できるメールアドレスを書く）。

### 6-2. 広告

**あり**（「アプリに広告が含まれていますか」→ はい）。解析待ちの画面に、バイク保険の一括見積り（インズウェブ、A8.net 経由のアフィリエイトリンク）の紹介を「PR」付きで出します。Google Play はアプリ内のアフィリエイト訴求も広告として扱うため「はい」にします。広告 SDK は使わず、画像の読み込みや計測タグもありません。リンクは別タブ（ブラウザ）で開きます。「広告を含む」バッジが付くことを了承した上で申告してください。

### 6-3. コンテンツのレーティング（IARC）

カテゴリは「ユーティリティ、生産性、コミュニケーション、その他」。質問にはすべて「いいえ」で答えます（暴力・性的な内容・不適切な言葉・薬物・ギャンブル・位置情報の共有・ユーザー同士のやり取りなどはいずれもありません）。詳細は [README.md の 7 章](./README.md#7-コンテンツのレーティング質問票の答え)。

### 6-4. ターゲット層

18 歳以上のみを選びます（運転する人向けのアプリで、子ども向けではない）。「子ども向けアプリ」には該当しません。

## 7. データ セーフティ（下書き）

Play Console の「データ セーフティ」フォームへの回答案です。**回答は実コードとドキュメントに基づいています**が、最終判断はオーナーが行ってください（データ収集の定義は Google のガイドが正本です）。
「共有」は、Google の定義上、サービス提供のために処理を委託する先（Clerk、Supabase、Vercel など。本アプリのデータを自社のために処理する事業者）への送信は含まれません。Gemini については扱いが分かれ得るので、保守的に「共有する」を選ぶ案を既定にしています。

### 7-1. 全体の質問

| 質問 | 回答 | 根拠 |
|---|---|---|
| アプリは必須のユーザーデータを収集・共有しますか | はい | ログイン時にメールアドレス等、AI 読み取りで写真を送信 |
| すべてのユーザーデータは転送中に暗号化されますか | はい | HTTPS（プライバシーポリシー 7 章） |
| ユーザーがデータの削除をリクエストする方法を提供していますか | はい | アプリ内でアカウントとクラウドのデータを削除できる（[api-account.md](../api-account.md)、プライバシーポリシー 6 章） |

### 7-2. 収集するデータの種類

| データの種類（Console の分類） | 収集 | 共有 | 一時的な処理のみ | 必須 / 任意 | 目的 | 内容と根拠 |
|---|---|---|---|---|---|---|
| 個人情報 → メールアドレス | はい | いいえ（Clerk は認証の委託先） | いいえ | 任意（ログインしたときだけ） | アプリの機能、アカウント管理 | Clerk がログイン用に取得（プライバシーポリシー 2 章） |
| 個人情報 → 名前 | はい | いいえ（同上） | いいえ | 任意（同上） | アカウント管理 | 氏名（表示名）。Google ログイン時はプロフィール画像も Clerk が取得する（FuelLens の画面では使っていない。申告するなら「個人情報 → その他」） |
| 個人情報 → ユーザー ID | はい | いいえ | いいえ | 任意（同上） | アプリの機能、アカウント管理 | Clerk のユーザー ID が DB の記録に紐づく（`lib/data/cloudStore.ts`、RLS） |
| 写真と動画 → 写真 | はい | はい（Google Gemini API。保守的な申告） | **はい** | 任意（AI 読み取りを使うときだけ） | アプリの機能 | レシート・メーターの写真を `/api/analyze` 経由で Gemini に送る。FuelLens のサーバー・DB・ストレージには保存しない（[api-analyze.md](../api-analyze.md)、プライバシーポリシー 2 章） |
| アプリのアクティビティ → その他のユーザー作成コンテンツ | はい | いいえ（Supabase はデータベースの委託先） | いいえ | 任意（ログインしたときだけクラウドに保存。未ログインは端末内のみで収集しない） | アプリの機能 | 給油記録（日付・スタンド名・燃料種別・給油量・金額・距離・メモ）、車両名・車種。金額を「金融情報」とみなす場合は「金融情報 → その他の金融情報」も追加 |
| アプリのアクティビティ → アプリのインタラクション（ページビュー） | はい | いいえ | いいえ | 必須（Web 解析は止められない） | 分析 | Vercel Web Analytics。Cookie なし、個人の追跡なし。URL のハッシュと utm 以外のクエリは除去（[operations.md 4-2](../operations.md#4-2-web-analyticsページビュー計測)） |
| アプリの情報とパフォーマンス → クラッシュ ログ・診断 | **条件付き** | いいえ | いいえ | 必須 | アプリの機能（不具合の調査） | Sentry を有効にした場合だけ。Vercel に `NEXT_PUBLIC_SENTRY_DSN` を設定していなければ「収集しない」。設定するなら「収集する」にして、ユーザー ID（Clerk の ID のみ）が紐づく点も申告（[operations.md 4-3](../operations.md#4-3-sentryエラー監視)） |

収集しないもの（コードに該当する処理がない）: 位置情報、連絡先、カレンダー、通話・SMS、音声、ファイル、広告 ID・端末 ID、健康・フィットネス、検索履歴、閲覧履歴（アプリ外）。
IP アドレスは、AI 読み取りの回数制限のためにサーバーのメモリ上で一時的に使うだけで DB には保存しません（プライバシーポリシー 2 章。ホスティング事業者のサーバーログには一般的な通信記録が残り得ます）。
カメラは、写真を撮るためにブラウザの標準のファイル選択（`capture="environment"`）を使います。アプリが常時カメラへアクセスする機能ではありません。

### 7-3. 「データはリクエストに応じて削除できる」の回答

- ログイン中のデータ: 設定 →「アカウント」→「アカウントを削除」で、クラウドの車両・記録とアカウント（Clerk）を削除。元に戻せません。
- ログインしていない間の端末内のデータ: 同じ場所の「この端末のデータをすべて削除」。
- 削除 URL に入れる先: https://fuel-lens.gadelog.com/privacy（6 章「保存期間と削除」）。
